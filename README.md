💻 Site — Curso Técnico em Desenvolvimento de Sistemas
📌 Sobre o projeto

Este projeto consiste em um site informativo sobre o curso técnico em Desenvolvimento de Sistemas, desenvolvido com HTML e CSS, utilizando o framework W3.CSS para estilização e organização dos elementos da página.

O site apresenta informações sobre o curso, sua grade curricular, o mercado de trabalho, as principais tecnologias utilizadas na área e um formulário de contato.

🎯 Objetivo

Criar uma página web que reúna informações relevantes sobre o curso técnico em Desenvolvimento de Sistemas, apresentando seus principais conteúdos e oportunidades profissionais de forma organizada e acessível.

🚀 Funcionalidades
Home: apresentação visual do curso por meio de logotipos e imagens.
Sobre o curso: descrição dos objetivos e das competências desenvolvidas durante a formação.
Grade curricular: apresentação das disciplinas dos três módulos do curso.
Mercado de trabalho: informações sobre a área de Tecnologia da Informação e suas oportunidades profissionais.
Tecnologias: exibição de imagens de linguagens e tecnologias utilizadas no desenvolvimento de sistemas.
Contato: apresentação de informações de contato e formulário para preenchimento de nome, e-mail, assunto e mensagem.
Menu lateral: navegação entre as seções da página por meio de links internos.
🛠️ Tecnologias utilizadas
HTML5: estruturação do conteúdo da página.
CSS3: personalização dos estilos visuais.
W3.CSS: framework utilizado para layout, espaçamento, cores e componentes responsivos.
Font Awesome 4.7: biblioteca de ícones para o menu e outras seções.

▶️ Como executar o projeto
Faça o download ou clone o repositório.
Verifique se o arquivo index.html está na pasta principal.
Confira se a pasta img contém todas as imagens necessárias.
Abra o arquivo index.html em um navegador, como Google Chrome, Microsoft Edge ou Firefox.

Não é necessário instalar dependências ou configurar um servidor para visualizar a página localmente. É necessária uma conexão com a internet para carregar as bibliotecas externas de CSS e ícones utilizadas pelo projeto.

📚 Conteúdo do curso

A página apresenta as disciplinas distribuídas em três módulos:

1º módulo: fundamentos da informática, programação e algoritmos, banco de dados, design digital e programação web.
2º módulo: desenvolvimento de sistemas, banco de dados, programação de aplicativos mobile, programação web e planejamento do TCC.
3º módulo: segurança da informação, sistemas embarcados, testes de software, programação mobile e web e desenvolvimento do TCC.
📩 Formulário de contato

O site possui um formulário com campos para nome, e-mail, assunto e mensagem.

Importante: na versão atual, o formulário ainda não possui integração com um serviço de envio de mensagens ou back-end. Portanto, o botão de envio não garante que os dados sejam transmitidos ou recebidos.

👨‍💻 Considerações finais

O projeto tem como finalidade apresentar o curso técnico em Desenvolvimento de Sistemas e demonstrar conhecimentos básicos de desenvolvimento web utilizando HTML, CSS, W3.CSS e Font Awesome.

É um projeto educacional que pode ser expandido e aprimorado conforme o aprendizado de novas tecnologias e práticas de desenvolvimento.
